# 🚀 Projeto de Portfólio – Dashboard de People Analytics

## 📌 Descrição

Este projeto tem como objetivo demonstrar a capacidade de transformar **dados de pessoas** em **insights estratégicos** para apoiar decisões de gestão.  

O trabalho consiste em desenvolver um **painel interativo em Power BI**, utilizando dados fictícios de RH (como turnover, absenteísmo, engajamento e headcount). O dashboard deve permitir que gestores visualizem rapidamente os principais indicadores e identifiquem tendências ou problemas.  

Além do painel, o projeto inclui:  
- Um **relatório analítico** explicando os resultados encontrados e sugerindo ações práticas.  
- Uma **apresentação em slides** voltada para líderes, com foco em storytelling simples e visual.  

## 🎯 Objetivos do Projeto
- Demonstrar habilidade em **coletar e organizar dados**.  
- Mostrar competência em **visualização e análise** com ferramentas de BI.  
- Evidenciar capacidade de **comunicar insights de forma clara** para diferentes públicos.  
- Aplicar conceitos práticos de **People Analytics**.  

## 📦 Entregáveis
- Dashboard interativo pronto.  
- Relatório com análises e recomendações.  
- Slides de apresentação para gestores.  

## ✅ Critérios de Sucesso
- KPIs bem definidos e relevantes.  
- Visualizações claras e intuitivas.  
- Insights práticos que apoiem decisões estratégicas.  

## 💡 Dica
Se não houver dados reais disponíveis, crie uma base fictícia no Excel simulando cenários de RH (ex.: turnover por departamento, absenteísmo por área, engajamento por equipe).
